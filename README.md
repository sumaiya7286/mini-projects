# Mini Projects

Small projects I built while learning web development: first with plain HTML, CSS and JavaScript, then with React.

## JavaScript (HTML, CSS, JS)

| Project | What it does | Concepts |
|---|---|---|
| [Todo App](javascript/todo-app) | Add, complete and delete tasks; saved in the browser | DOM manipulation, events, localStorage |
| [Weather App](javascript/weather-app) | Search any city to see temperature, humidity and wind speed | Fetch API, async/await, Open-Meteo API (no key needed) |
| [Guess Game](javascript/guess-game) | Guess the random number, with score and attempts | Game logic, DOM updates |
| [Notes App](javascript/notes-app) | Write and save notes | localStorage, dynamic elements |
| [Quiz App](javascript/quiz-app) | Multiple-choice quiz with score at the end | Arrays of objects, event handling |

To run any of these, open its `index.html` in a browser.

## React

| Project | What it does | Concepts |
|---|---|---|
| [Todo App (Context API)](react/todo-context) | Todo app with add, edit, complete and delete | Context API, localStorage, components |
| [Currency Converter](react/currency-converter) | Convert between currencies with live rates | API fetch, custom hook |
| [Theme Switcher](react/theme-switcher) | Light and dark mode toggle | Context API, Tailwind dark mode |
| [Password Generator](react/password-generator) | Random passwords with options and copy button | useCallback, useRef, useEffect |

To run a React project:

```bash
cd react/<project-name>
npm install
npm run dev
```

## Tech stack

HTML, CSS, JavaScript, React, Tailwind CSS, Vite, Git and GitHub.
