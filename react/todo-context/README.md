# Todo App (Context API)

A todo app where you can add, edit, complete and delete tasks. Tasks are saved in localStorage.

**Tech stack:** React, Context API, Tailwind CSS, Vite

## How to run

```bash
npm install
npm run dev
```

## What I learned

- Sharing state across components with `createContext` and `useContext`
- Saving data with `useEffect` and localStorage
- Splitting UI into reusable components
